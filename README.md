# Sistema de Gestión de Tutorías Académicas

**Descripción breve:** 
Sistema web desarrollado para centralizar y automatizar la solicitud, asignación y seguimiento de tutorías académicas entre docentes y estudiantes. Permite a los administradores gestionar tutores, a los estudiantes solicitar tutorías y a los tutores aceptar o rechazar las solicitudes de manera ágil y segura.

## Tecnologías Utilizadas
*   **Backend:** PHP 8.2 con Laravel 11
*   **Base de Datos:** MySQL 
*   **Frontend:** Blade, Tailwind CSS
*   **Servidor Local:** XAMPP
*   **Control de Versiones:** Git / GitHub
